# 📋 Доска статусов задач по исполнителям

Веб-приложение в виде сводной таблицы для отслеживания статусов задач по исполнителям (учителям) и предметам.

![React](https://img.shields.io/badge/React-18-blue)
![Vite](https://img.shields.io/badge/Vite-6-purple)
![TailwindCSS](https://img.shields.io/badge/Tailwind-4-cyan)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)

## ✨ Возможности

- **Сводная таблица** — строки (исполнители) × столбцы (класс + предмет)
- **Статусы задач** с цветовым кодированием:
  - ⬜ Не сделано (серый)
  - 🟡 На проверке (жёлтый)
  - 🟠 Доработка (оранжевый)
  - 🟢 Завершено (зелёный)
- **Редактирование структуры** — добавление/удаление/переименование строк и столбцов
- **Автосохранение** в `localStorage` — данные сохраняются при перезагрузке
- **Sticky-заголовки** — шапка и первый столбец фиксируются при прокрутке
- **Статистика** — подсчёт задач по каждому статусу
- **Адаптивный дизайн** — работает на мобильных устройствах

## 🛠 Технологии

- **React 18** — UI-библиотека
- **TypeScript** — типизация
- **Vite** — сборщик и dev-сервер
- **Tailwind CSS 4** — стилизация
- **Lucide React** — иконки
- **uuid** — генерация уникальных ID

## 🚀 Запуск проекта

### Предварительные требования

- [Node.js](https://nodejs.org/) версии 18 или выше
- [npm](https://www.npmjs.com/) (устанавливается вместе с Node.js)

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

После этого откройте браузер и перейдите по адресу, указанному в терминале (обычно `http://localhost:5173`).

### Сборка для продакшена

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`. Их можно разместить на любом статическом хостинге.

### Проверка типов

```bash
npm run typecheck
```

## 💡 Использование

1. **Изменение статуса** — выберите нужный статус в выпадающем списке ячейки
2. **Переименование** — дважды кликните по заголовку строки/столбца или нажмите на иконку ✏️
3. **Добавление** — нажмите кнопку «+» рядом с заголовком или используйте кнопки внизу таблицы
4. **Удаление** — нажмите на иконку 🗑️ рядом с названием (нельзя удалить последнюю строку/столбец)
5. **Сброс** — нажмите «Сбросить всё» для очистки всех данных (с подтверждением)
